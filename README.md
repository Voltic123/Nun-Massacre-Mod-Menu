# ⚠️ MUST NEED BEPINEX WIN X64 ⚠️

**REQUIREMENT:** BepInEx Win x64

## Installation
1. Install BepInEx Win x64.
2. Open your game's installation directory.
3. Navigate to the `BepInEx\plugins` folder.
4. Place the VCLIENT DLL file inside the `plugins` folder.
5. Launch the game.

**Installation Path:**
```text
BepInEx\plugins
```


# ONLY WORKS ON THE DEFINITIVE EDITION OF NUN MASSACRE NOT THE OLDER VERSION

# VCLIENT 1.0 – Features




## Visuals / ESP
- [x] **Nun ESP** – Box, distance, and line indicators
- [x] **Skeleton ESP** – Displays skeleton overlays
- [x] **Item ESP** – Shows item dots and names
- [x] **Item ESP Limit** – Shows 20 items; hides 3 items outside the map
- [x] **RGB ESP** – RGB-colored ESP visuals
- [x] **RGB Menu** – RGB menu interface
- [x] **Custom FOV** – With Slider
- [x] **FOV Slider** – Adjustable FOV

## Cheats / Player Mods
- [x] **God Mode** – Enables god mode
- [x] **Invisibility** – Nun cannot see or hear you
- [x] **Freeze Nun** – Freezes the Nun
- [x] **Speed Boost** – Adjustable movement speed
- [x] **Speed Multiplier** – Adjustable speed (default: 2.00x)
- [x] **Infinite Ammo** – Unlimited ammunition
- [x] **Infinite Stamina** – Unlimited stamina
- [x] **Noclip** – Move freely through the map
  - WASD – Movement
  - Space – Move up
  - CTRL – Move down
  - Shift – Move faster
- [x] **Noclip Speed** – Adjustable noclip speed (default: 6.0)

## Menu / UI
- [x] **HOME Keybind** – Show or hide the menu
- [x] **Freeze Game While Menu Is Open** – Pauses the game while interacting with the menu

## General
- **Client:** VCLIENT 1.0
- **Menu Toggle:** HOME
- **Customizable Settings:** FOV, Speed, and Noclip Speed
